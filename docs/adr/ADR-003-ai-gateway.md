# ADR-003 · 生成式 AI 经独立网关 + 安全围栏（采纳）

- 状态：**采纳**（p0 #4 合规口径，2026-10-17）
- 决策范围：生成式 AI 的合规与接入方式（p5）
- 关联：`docs/prd-trace/decision-checklist-13.md` D7、`apps/server/internal/ports`（LLM/OCR/ASR）、`docs/ops/alerts.md`

## 背景

p5 若直接对接多家模型，需逐家评估备案/境内模型/数据出境（#4），合规成本高。立项方决策：
**不逐家评估，统一经「独立 AI 网关」接入，由网关执行安全围栏**。

## 决策

1. **统一网关出口**：所有生成式调用经独立 AI 网关（境内托管/自建代理，暴露 HTTP API），平台**不直连**模型供应商。
   适配器 `adapters/llm/gateway` 实现 `ports.LLM`；配置 `CATCUBE_AI_GATEWAY_URL` / `CATCUBE_AI_GATEWAY_KEY`；未配置回退 `llm.DevClient`（开发态）。

2. **安全围栏在网关侧**（合规责任由网关承担）：
   - 输入/输出内容安全过滤（违规内容拦截、拒答）；
   - 提示词注入/越权防护；
   - 生成内容与请求的可审计留痕（网关侧日志）；
   - 备案/境内模型/数据出境由网关方保证。

3. **平台侧围栏（双保险，保留不变）**：
   - 特性开关门禁（默认关闭）、配额/成本（`ai.*` settings）、上游失败/关闭一律 `030001` 降级；
   - 隐私剥离 `sanitizeForPrompt`（手机号/证件号/邮箱/微信号）**先于**出网；
   - 输出收敛：字段池白名单、TagSet/类型幻觉丢弃、只读建议不自动裁决。

4. **不改动既有契约**：`ports.LLM` 签名不变；仅替换生产适配器实现（Dev → Gateway）；评测门禁
   `internal/modules/ai/eval_test.go` 对新适配器同样适用。

5. **语音（ASR）**：不属本网关范围，二期按 `ports.ASR` 接入。

## 备选方案与否决理由

| 备选 | 否决理由 |
| --- | --- |
| 平台直连多家模型，逐家办理备案/数据出境 | 合规与维护成本高，与「不过度复杂」不符 |
| 仅靠平台侧过滤 | 无法满足生成式 AI 服务备案与内容安全要求 |
| 关闭 AI | 与 D6（纳入一期文本场景）冲突 |

## 影响

- p5 §1.2：生产 LLM 适配器改为「网关适配器」（见上），不再逐家选型；
- 运维：新增网关配置项 `CATCUBE_AI_GATEWAY_URL` / `CATCUBE_AI_GATEWAY_KEY`（未配置即开发态）；
- 合规：#4 由「平台逐项评估」转为「网关合规承诺 + 平台双保险围栏」。
