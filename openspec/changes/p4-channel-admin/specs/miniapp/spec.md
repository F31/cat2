# miniapp 增量规格（p4-channel-admin，运营商身份）

## ADDED Requirements

### Requirement: 运营商移动端身份
运营商能力 SHALL 并入小程序（不设独立 Web 后台）：身份卡（身份与所属区域）、区域推广（专属链接/邀请码）、拉人归属记录、佣金明细、提现申请、业绩概览（本月新增付费会员/佣金合计/保底完成度）。

#### Scenario: 身份入口可见性
- **WHEN** 非运营商用户打开个人中心
- **THEN** 不显示运营商入口；运营商用户显示身份卡与六个功能入口

### Requirement: 资金红线展示
用户 SHALL 直接向平台付费，平台月结佣金；小程序内 SHALL NOT 出现「发展下级」「二级分成」类入口或文案。

#### Scenario: 页面走查
- **WHEN** 审查运营商相关页面
- **THEN** 不存在发展下级的入口与话术
