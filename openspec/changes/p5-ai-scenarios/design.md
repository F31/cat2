## 本阶段执行决策

1. **ai 是纯增强**：所有场景都是「替代填表的辅助入口」，每个场景的降级路径（原手动表单/关键词搜索/人工客服）必须在关闭开关时完整可用，回归测试覆盖。
2. **结构化输出优先**：Draft/Extract 一律 JSON Schema 约束输出，两次失败即降级，不做自由文本解析。
3. **提示词即配置但有门禁**：提示词版本存 `ai_prompt` 可后台调整，但变更必须通过固定样本集评测才生效。
4. **审核辅助零权力**：AI 预分类与摘要只作为审核员的展示建议，不接入状态机、不触发任何自动处罚。
