## 本阶段执行决策

1. **演练即测试**：降级矩阵的每一行都落成自动化或半自动化演练脚本（注入故障→断言降级行为→恢复），不是文档勾选。
2. **压测数据隔离**：压测使用独立库/schema（含 `tlm_` 埋点表），压测后销毁，不污染业务库。
3. **灰度与回滚**：特性开关支持按用户/比例/白名单；每个灰度批次定义明确回滚动作（开关关闭即可回退）。
4. **冻结范围**：本阶段不接收新需求；待确认项遗留问题（如 #22 圈卡片混排若产品确认要做）须另行立项变更，不混入上线窗口。
