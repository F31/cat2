# 错误码登记册（MMNNNN）

错误码为 6 位数字：`MM` 模块前缀 + `NNNN` 模块内序号（0001 起）。`code=0` 表示成功。
新增错误码必须先在此登记，再到模块内使用；CI 校验生产方与契约一致。

## 前缀分配

| MM | 模块 | 说明 |
| --- | --- | --- |
| 00 | kernel/通用 | 参数错误、未认证、无权限、限流、幂等冲突、上游失败 |
| 01 | identity | 登录、令牌、账号状态、注销 |
| 02 | trust | 审核、举报、敏感词、限制 |
| 03 | ai | LLM/OCR/ASR 网关 |
| 04 | dict | 字典与标签 |
| 05 | media | 文件上传与引用 |
| 06 | profile | 名片与画像 |
| 07 | msg | 会话 |
| 08 | trade | 支付、订单、退款 |
| 09 | social | 收藏、关注、点赞 |
| 10 | verify | 认证与核验 |
| 11 | content | 内容发布 |
| 12 | membership | 会员与订阅 |
| 13 | cube | 猫立方 |
| 14 | circle | 圈子 |
| 15 | channel | 渠道/运营商 |
| 16 | discovery | 搜索与推荐 |
| 17 | notice | 通知 |

## 通用段（00）明细

| 码 | 含义 | HTTP |
| --- | --- | --- |
| 0 | 成功 | 200 |
| 000001 | 参数错误 | 400 |
| 000002 | 未认证/令牌失效 | 401 |
| 000003 | 无权限（策略拒绝） | 403 |
| 000004 | 资源不存在 | 404 |
| 000005 | 状态机非法转移 | 409 |
| 000006 | 幂等键冲突（同键不同请求体） | 409 |
| 000007 | 配额超限 | 429 |
| 000008 | 上游调用失败（微信/OSS 等） | 502 |
| 000009 | 内部错误 | 500 |

## 各模块明细

模块内序号由各模块文档（docs/modules/）维护；本表只保证前缀不冲突。

### 01 identity

| 码 | 含义 | HTTP |
| --- | --- | --- |
| 010001 | 微信 code 无效或已使用 | 400 |
| 010002 | refresh token 失效或被撤销 | 401 |
| 010003 | 账号已注销 | 403 |
| 010004 | 账号被停用（封禁） | 403 |
| 010005 | 短信验证码无效或已过期 | 400 |
| 010006 | 登录尝试过于频繁（锁定） | 429 |
| 010007 | 手机号缺失或非法 | 400 |

### 02 trust

| 码 | 含义 | HTTP |
| --- | --- | --- |
| 020001 | 敏感词命中（先提示，再记分） | 400 |
| 020002 | 内容机检未通过 | 400 |
| 020003 | 用户处于限制期，禁止发布 | 429 |
| 020004 | 举报原因非法 | 400 |
| 020005 | 审核任务不存在或已处理 | 404 |

### 06 profile

| 码 | 含义 | HTTP |
| --- | --- | --- |
| 060001 | 名片不存在 | 404 |
| 060002 | 名片字段校验失败（名称必填/简介或核心优势超长） | 400 |
| 060003 | 字段已被认证锁定，不可自行修改 | 403 |
| 060004 | 标签非法（行业/区域/需求/供给 code 未登记） | 400 |

### 10 verify

| 码 | 含义 | HTTP |
| --- | --- | --- |
| 100001 | 姓名/证件号格式或协议勾选校验失败 | 400 |
| 100002 | 实名核验未通过（姓名与证件号不一致） | 400 |
| 100004 | 已完成实名认证 | 409 |
| 100005 | 暂不支持的认证类型 | 400 |

### 11 content

| 码 | 含义 | HTTP |
| --- | --- | --- |
| 110001 | 内容不存在或不可见 | 404 |
| 110002 | 无权操作该内容 | 403 |
| 110003 | 字段校验失败（必填/超长/标题≤50字） | 400 |
| 110004 | 发布需先完成实名认证 | 403 |
| 110005 | 未知内容类型 | 400 |

### 09 social

| 码 | 含义 | HTTP |
| --- | --- | --- |
| 090001 | 目标引用非法（非 type:id 或 id≤0） | 400 |
| 090002 | 不支持的收藏分类 | 400 |

### 08 trade

| 码 | 含义 | HTTP |
| --- | --- | --- |
| 080001 | 订单/支付单不存在 | 404 |
| 080002 | 无权操作该订单 | 403 |
| 080003 | 金额/业务类型非法 | 400 |
| 080004 | 订单状态不可支付 | 409 |
| 080005 | 支付回调验签失败 | 400 |
| 080006 | 退款金额非法 | 400 |

> 其余模块在对应 change（p2 起）落地时补充明细。
