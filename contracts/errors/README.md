# 错误码登记册（MMNNNN）

错误码为 6 位数字：`MM` 模块前缀 + `NNNN` 模块内序号（0001 起）。`code=0` 表示成功。
新增错误码必须先在此登记，再到模块内使用；CI 校验生产方与契约一致。

## 前缀分配

| MM | 模块 | 说明 |
| --- | --- | --- |
| 00 | kernel/通用 | 参数错误、未认证、无权限、限流、幂等冲突、上游失败 |
| 01 | identity | 登录、令牌、账号状态、注销 |
| 02 | trust | 审核、举报、敏感词、限制 |
| 03 | ai | LLM/OCR/ASR 网关 |
| 04 | dict | 字典与标签 |
| 05 | media | 文件上传与引用 |
| 06 | profile | 名片与画像 |
| 07 | msg | 会话 |
| 08 | trade | 支付、订单、退款 |
| 09 | social | 收藏、关注、点赞 |
| 10 | verify | 认证与核验 |
| 11 | content | 内容发布 |
| 12 | membership | 会员与订阅 |
| 13 | cube | 猫立方 |
| 14 | circle | 圈子 |
| 15 | channel | 渠道/运营商 |
| 16 | discovery | 搜索与推荐 |
| 17 | notice | 通知 |

## 通用段（00）明细

| 码 | 含义 | HTTP |
| --- | --- | --- |
| 0 | 成功 | 200 |
| 000001 | 参数错误 | 400 |
| 000002 | 未认证/令牌失效 | 401 |
| 000003 | 无权限（策略拒绝） | 403 |
| 000004 | 资源不存在 | 404 |
| 000005 | 状态机非法转移 | 409 |
| 000006 | 幂等键冲突（同键不同请求体） | 409 |
| 000007 | 配额超限 | 429 |
| 000008 | 上游调用失败（微信/OSS 等） | 502 |
| 000009 | 内部错误 | 500 |

## 各模块明细

模块内序号由各模块文档（docs/modules/）维护；本表只保证前缀不冲突。

### 01 identity（占位明细）

| 码 | 含义 |
| --- | --- |
| 010001 | 微信 code 无效或已使用 |
| 010002 | refresh token 失效或被撤销 |
| 010003 | 账号已注销 |
| 010004 | 账号被停用 |

### 02 trust（占位明细）

| 码 | 含义 |
| --- | --- |
| 020001 | 敏感词命中（先提示，再记分） |
| 020002 | 内容机检未通过 |
| 020003 | 用户处于限制期，禁止发布 |

> 其余模块在对应 change（p2 起）落地时补充明细。
